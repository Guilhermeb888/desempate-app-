# Desempate App

Aplicativo web interativo desenvolvido com Inteligência Artificial para apoiar na tomada de decisões complexas, oferecendo análise SWOT, tabela de prós e contras e tabela comparativa estruturada.

---

## 🚀 Sobre o Projeto

O **Desempate App** é uma ferramenta voltada para auxiliar indivíduos e equipes a estruturarem suas escolhas de forma lógica e visual. Com uma interface limpa e intuitiva construída em React/TypeScript, o sistema utiliza recursos avançados para gerar insights, pesar vantagens e desvantagens e realizar análises estratégicas (SWOT) de cenários ou alternativas.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando uma pilha moderna baseada em web:

* **TypeScript** (99% do código)
* **Vite** (Build tool e servidor de desenvolvimento)
* **Bun** (Gerenciador de pacotes e execução)
* **Tailwind CSS / Componentes estilizados** (para o design responsivo)
* **Integração com IA** para geração e análise de dados de decisão
